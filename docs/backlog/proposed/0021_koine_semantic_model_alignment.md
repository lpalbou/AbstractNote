# Align the claim vocabulary with the Koine semantic model

## Idea
The AbstractSemantics redesign (Koine v2) replaces the closed predicate list with schema.org + SKOS, adds qualified statements and certainty tokens. AbstractNote already uses certainty tokens and name/alias fields; when the registry moves, map `ex:` predicates and add rdf:Statement-style qualification for disputed claims.

## Status
Proposed; not an implementation commitment. Promote to planned with a code-reality section when scheduled.
